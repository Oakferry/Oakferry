👨‍💻 Sobre mim

Estou desenvolvendo minha experiência em programação principalmente através de projetos práticos.

Tenho trabalhado com desenvolvimento web, automações, integrações e sistemas com regras de negócio, passando por projetos acadêmicos, sites institucionais e aplicações que nasceram de necessidades reais.

No processo, gosto de entender como cada parte funciona, melhorar o que já foi construído e experimentar novas ferramentas quando elas fazem sentido.

Também venho incorporando ferramentas de IA ao desenvolvimento para apoiar pesquisas, prototipação, revisão de código e aprendizado de novas tecnologias — sem deixar de lado a lógica, as decisões técnicas e o entendimento do projeto.
