👨‍💻 Sobre mim

Sou apaixonado por tecnologia e por transformar ideias, necessidades e problemas reais em soluções digitais funcionais.

Atualmente, venho desenvolvendo projetos envolvendo desenvolvimento web, automação, integrações, arquitetura de software e experiências digitais, enquanto aprofundo meus conhecimentos em engenharia de software.

Uma parte importante da minha evolução tem sido explorar novas formas de desenvolver software com IA integrada ao processo de engenharia.

Uso ferramentas e agentes de IA como apoio para:

* explorar soluções;
* estruturar projetos;
* prototipar interfaces;
* investigar problemas;
* revisar e refatorar código;
* documentar decisões;
* validar ideias com mais rapidez.

A proposta não é simplesmente gerar código mais rápido, mas utilizar essas ferramentas para entender melhor o problema, testar hipóteses, aprender novas tecnologias e construir soluções cada vez melhores.
